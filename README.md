## Portfolio Projects

### NSW Open Data AI Search

An AI-assisted search application for the Data.NSW catalogue that helps users discover NSW Government datasets using everyday language.

The application combines semantic embeddings with field-aware keyword retrieval and weighted reciprocal rank fusion. It also includes relevance controls, dataset-series grouping, structured filters, result sorting, pagination and a responsive Streamlit interface.

The catalogue and production search indexes are rebuilt automatically through a daily GitHub Actions workflow and published through GitHub Releases.

### NSW Open Data Catalogue Tracker

A Python data collection and analysis project using the Data.NSW CKAN API to collect, clean, analyse and visualise metadata about public datasets published by NSW Government organisations.

The project explores dataset publishing activity, resource formats, machine-readable dataset availability and catalogue metadata update patterns.

### NSW Road Traffic Volume Analysis

A Python data analysis project using Transport for NSW traffic count data to explore recorded road traffic volumes by station, road corridor, suburb, local government area and year.

The project includes data download, profiling, cleaning, preparation, exploratory analysis, station coverage review and visualisation.
